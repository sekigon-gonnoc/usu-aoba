# usu-aoba

usu-aobaはnRF52840を搭載した、乾電池駆動対応の薄型マイコンボードです。

キーボード基板とはFPCケーブルで接続でき、18本のGPIOを利用可能です。さらに、トラックパッドやトラックボールなどの拡張モジュールを接続するための6ピンFPCコネクタ ([KDK-Link](https://kdk-link.pages.dev/))も搭載しています。

省スペースな構成で、薄型ワイヤレスキーボードの製作に適しています。

![](img/usu-aoba-rev1.jpg)

本ページははusu-aoba rev.1の情報です。
rev.1では消費電力を削減し、拡張ポートの数が3に増えています。また、1つ目の拡張ポートのピン割り当てが変更されており、GPIO7~10から独立しました。
電源・マトリクス用の20pコネクタのピン配置は変わっていません。

rev.0の情報は[こちら](rev0.md)

## ピン配置

0.5mmピッチの20p FFCコネクタと6p FFCコネクタを搭載しています。

## ブートローダ起動方法

リセットスイッチを素早く2回押してください

## ファームウェア

[ZMK用コンポーネント](https://github.com/sekigon-gonnoc/zmk-component-usu-aoba)

ビルド時にはボードバージョンに1を指定してください。

```yaml
include:
  - board: usu_aoba@1.0.0
    shield: <your-shield>
```
